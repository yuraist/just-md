# JustMD

Read README.md for architecture and commands, docs/roadmap.md for release readiness, docs/known-issues.md for known issues, and docs/distribution.md when shipping. Confirm the current App Store status before claiming a release is live.

Keep the native NSDocument editor, read mode and existing app scope intact. Use the existing Swift Testing target for behavior changes. Build/test through xcodebuild using the README commands.

Keep credentials and generated signing/release artifacts local. Shared appstoreconnect and native-apple-design skills are available under ~/.agents/skills.
