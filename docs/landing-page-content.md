## Hero

**CTA Button:** Download on the Mac App Store

## Pain Points
> You open a README and it's a thicket of `#`, `**`, and `|` pipes — you spend more time parsing markup than reading your own words.
> Your notes app renders markdown beautifully… inside its own library, its own sync, its own subscription. Your files are hostages.
> You just want to edit the file. Not import it, not create a vault, not configure a preview pane.
> Electron "minimal" editors take three seconds to open a text file and type with a visible lag.

**Transition:** Your markdown files deserve a Mac app that treats them like documents.

## Solution
**Heading:** One file, one window, one focused writing surface.
**Body:** JustMD opens your local `.md` files like TextEdit opens text — instantly, natively, no library and no lock-in. Instead of raw markup, you see the document: syntax markers hide on every line except the one you're editing, lists get real bullets and clickable checkboxes, tables align into grids. Flip to Read mode for a fully rendered page.

## How It Works
1. **Open** — double-click any `.md` file in Finder (or drop it on the icon).
2. **Write** — markdown styles as you type; the caret line reveals the raw syntax when you need it.
3. **Read** — ⇧⌘E switches to a rendered view with real tables, images, and links.
4. **Done** — autosave and macOS Versions keep the file safe, exactly where it lives.

## Benefits
- Read your own notes at a glance — no syntax noise between you and the text.
- Keystrokes land instantly, even in long documents — it's native AppKit, not a browser in a costume.
- Your files stay yours: plain `.md` on disk, no vault, no sync, no account.
- Check off task lists by clicking, not by editing brackets.
- Make it yours: five built-in themes plus shareable custom palettes.
